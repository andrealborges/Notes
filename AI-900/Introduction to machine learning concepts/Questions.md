# Machine Learning Concepts – 10 Question Test

1. What is the primary goal of machine learning?  

- [ ] a) To write software without human input  
- [ ] b) To use data from past observations to predict unknown outcomes  
- [ ] c) To eliminate the need for data scientists  
- [ ] d) To replace all traditional statistics  

Answer: B
* Machine learning is about using historical data to build predictive models. The emphasis is not on replacing statistics or writing software automatically, but on learning patterns that generalize to new data.

2. Which of the following best describes supervised learning?  

- [ ] a) Training a model with labeled data to predict outcomes  
- [ ] b) Training a model with unlabeled data to find patterns  
- [ ] c) Training a model to mimic human behavior without data  
- [ ] d) Training a model that adjusts without feedback  

Answer: A
* In supervised learning, you provide both inputs (features) and known outputs (labels). The model learns the mapping so it can predict the output for new, unseen inputs. Example: predicting whether a tumor is malignant (yes/no) based on medical test results.

3. In unsupervised learning, how does the algorithm typically learn?  

- [ ] a) By mapping inputs to labeled outputs  
- [ ] b) By trial and error with a reward system  
- [ ] c) By finding hidden structures and groupings in unlabeled data  
- [ ] d) By following explicit programming rules  

Answer: C
* Unsupervised learning doesn’t have labeled outcomes. Instead, it looks for patterns like clusters or associations within the dataset. Example: grouping customers into market segments.

4. Which machine learning approach is used when an agent learns by receiving rewards or penalties for actions taken?  

- [ ] a) Supervised learning  
- [ ] b) Unsupervised learning  
- [ ] c) Reinforcement learning  
- [ ] d) Deep learning  

Answer: C
* This approach uses feedback in the form of rewards or penalties. An agent (like a robot or game player) explores actions and learns which ones maximize long-term reward.

5. What is the process of dividing data into training and test sets primarily intended to achieve?  

- [ ] a) To reduce the size of the dataset  
- [ ] b) To prevent overfitting and evaluate model generalization  
- [ ] c) To make the model run faster  
- [ ] d) To remove bias from the dataset  

Answer: B
* Splitting into training and test sets ensures the model learns from one dataset and is evaluated on unseen data. This helps check if the model generalizes instead of memorizing training examples.

6. Which of the following is an example of regression?  

- [ ] a) Predicting whether an email is spam or not  
- [ ] b) Predicting the price of a house based on its features  
- [ ] c) Clustering customers by purchasing habits  
- [ ] d) Identifying handwritten digits  

Answer: B
* Regression is used when the target is a continuous value (price, temperature, sales volume, etc.). In contrast, spam detection or digit recognition are classification tasks.

7. Classification problems typically involve predicting:  

- [ ] a) Continuous numeric values  
- [ ] b) Categories or discrete labels  
- [ ] c) Missing data in a dataset  
- [ ] d) The exact sequence of future events  

Answer: B
* Classification involves predicting categories such as "spam vs not spam," "disease vs no disease," or "image of a cat vs dog."

8. What is the main risk of overfitting in machine learning? 

- [ ] a) The model runs too slowly  
- [ ] b) The model memorizes training data and fails on new data  
- [ ] c) The model uses too little data and underperforms  
- [ ] d) The model cannot converge during training  

Answer: B
* Overfitting means the model fits noise and specifics of the training set, losing its ability to generalize. It performs very well on training data but poorly on test data.

9. Which of these is an example of clustering (an unsupervised learning task)?  

- [ ] a) Segmenting customers into groups based on buying behavior  
- [ ] b) Predicting tomorrow’s temperature  
- [ ] c) Detecting fraudulent credit card transactions  
- [ ] d) Translating English text into Spanish  

Answer: A
* Clustering is an unsupervised method used to group data points based on similarity. No predefined labels are given — the algorithm finds natural groupings.

10. In the machine learning workflow, which step comes immediately before training the model?  

- [ ] a) Model deployment  
- [ ] b) Data preparation and feature engineering  
- [ ] c) Model evaluation  
- [ ] d) Inference

Answer: B
* Before training, data must be cleaned, transformed, and structured into features the model can understand. This step is critical because the quality of features strongly affects model performance.
