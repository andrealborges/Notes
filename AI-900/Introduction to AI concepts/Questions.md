# AI Concepts – 10 Question Test

1. What is the main difference between large language models (LLMs) and small language models (SLMs)?

- [ ] a) LLMs are only used for speech recognition, while SLMs are for text generation
- [ ] b) LLMs use more data and have more variables, making them more general but costlier
- [ ] c) SLMs are more accurate than LLMs in all scenarios
- [ ] d) LLMs are trained without internet data

Answer: B
* LLMs are trained with massive datasets and contain billions of parameters, making them capable of handling a wide range of topics. However, they require more computational resources. SLMs are smaller, cheaper, and more efficient for specialized domains.

2. Which of the following is not listed as a common use of generative AI?
- [ ] a) Automated translation between languages
- [ ] b) Creating chatbots to assist users
- [ ] c) Processing expense claims from scanned forms
- [ ] d) Summarizing complex documents

Answer: C
* This task is part of data and insight extraction, not generative AI. Generative AI focuses on creating new content like text, images, and summaries. 

3. In computer vision, what does semantic segmentation do that object detection does not?
- [ ] a) Identifies audio from images
- [ ] b) Labels the main subject of an image
- [ ] c) Pinpoints the individual pixels belonging to an object
- [ ] d) Creates a 3D model of the object

Answer: C
* Semantic segmentation goes beyond drawing bounding boxes — it identifies exactly which pixels in the image correspond to the object, making it more precise for detailed analysis.

4. Which scenario is an example of combining computer vision with generative AI in a multi-modal model?
- [ ] a) Translating text between languages
- [ ] b) Auto-captioning images with descriptive sentences
- [ ] c) Classifying documents by topic
- [ ] d) Detecting language sentiment

Answer: B
* This combines computer vision (understanding what’s in the image) with generative AI (producing descriptive text).

5. What is speech synthesis primarily used for?
- [ ] a) Converting text into audible spoken language
- [ ] b) Translating speech from one language to another in text form
- [ ] c) Detecting emotions in spoken voice
- [ ] d) Removing background noise from audio

Answer: A
* Speech synthesis (text-to-speech) converts written text into spoken output. This is the opposite of speech recognition (speech-to-text).

6. Which of the following is not a common NLP task mentioned in the module?
- [ ] a) Entity extraction
- [ ] b) Text classification
- [ ] c) Speech-to-text transcription
- [ ] d) Sentiment analysis

Answer: C
* Speech-to-text belongs to the speech category, not NLP. NLP focuses on analyzing and understanding written text, such as classification, sentiment, and entity extraction.

7. What is the technology called that serves as the basis for most document analysis solutions?
- [ ] a) Optical character recognition (OCR)
- [ ] b) Semantic segmentation
- [ ] c) Speech synthesis
- [ ] d) Entity extraction

Answer: A
* OCR detects text from images (e.g., scanned documents). More advanced versions can identify specific fields or data points from documents.

8. Which responsible AI principle focuses on ensuring AI solutions don’t exclude certain groups of users?
- [ ] a) Transparency
- [ ] b) Inclusiveness
- [ ] c) Fairness
- [ ] d) Accountability

Answer: B
* Inclusiveness ensures that AI works for all groups, avoiding exclusion based on factors like disability, language, or access to technology.

9. A bank discloses that its loan-approval system uses AI and explains the type of training data it used (without revealing private details). Which responsible AI principle does this illustrate?
- [ ] a) Reliability and safety
- [ ] b) Transparency
- [ ] c) Fairness
- [ ] d) Inclusiveness

Answer: B
* Transparency means clearly explaining how an AI system works, its purpose, and the nature of its training data without revealing private details.

10. In responsible AI, what is one method an AI-powered robot can use to avoid causing harm when identifying objects?
- [ ] a) Only process one object at a time
- [ ] b) Use a probability confidence threshold before taking physical action
- [ ] c) Store all visual data indefinitely for safety
- [ ] d) Prioritize speed over accuracy

Answer: B
* This ensures the AI is confident enough in object recognition before interacting, reducing the risk of harm or mistakes.
