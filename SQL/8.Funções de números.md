## 54. **Arredondar um Número (ROUND)**

   ```sql
   SELECT ROUND(coluna_numero, numero_de_decimais) AS numero_arredondado
   FROM nome_da_tabela;
   ```

   - **Descrição:** Arredonda um número para o número de casas decimais especificadas.
   - **Exemplo:**  
     ```sql
     SELECT ROUND(salario, 2) AS salario_arredondado 
     FROM funcionarios;
     ```
