## 99. **Uso de Window Functions em `UPDATE` (Atualizar Dados com Função de Janela)**

   ```sql
   WITH ranked_salarios AS (
     SELECT id, ROW_NUMBER() OVER (PARTITION BY departamento ORDER BY salario DESC) AS rank_salario
     FROM funcionarios
   )
   UPDATE funcionarios
   SET bonus = 500
   WHERE id IN (SELECT id FROM ranked_salarios WHERE rank_salario = 1);
   ```

   - **Descrição:** Atualiza o valor de bônus para os funcionários com o maior salário (rank 1) em cada departamento.
   - **Exemplo:**
