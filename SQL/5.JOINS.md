## 25. **INNER JOIN**

   ```sql
   SELECT t1.coluna1, t2.coluna2
   FROM tabela1 t1
   INNER JOIN tabela2 t2 ON t1.coluna_comum = t2.coluna_comum;
   ```

   - **Descrição:** Retorna os registros que possuem correspondência em ambas as tabelas.
   - **Exemplo:**  
     ```sql
     SELECT funcionarios.nome, departamentos.nome 
     FROM funcionarios 
     INNER JOIN departamentos ON funcionarios.departamento_id = departamentos.id;
     ```

---

## 26. **LEFT JOIN (ou LEFT OUTER JOIN)**

   ```sql
   SELECT t1.coluna1, t2.coluna2
   FROM tabela1 t1
   LEFT JOIN tabela2 t2 ON t1.coluna_comum = t2.coluna_comum;
   ```

   - **Descrição:** Retorna todos os registros da tabela da esquerda (tabela1), e os registros correspondentes da tabela da direita (tabela2). Se não houver correspondência, retorna `NULL` para as colunas da tabela da direita.
   - **Exemplo:**  
     ```sql
     SELECT funcionarios.nome, departamentos.nome 
     FROM funcionarios 
     LEFT JOIN departamentos ON funcionarios.departamento_id = departamentos.id;
     ```

---

## 27. **RIGHT JOIN (ou RIGHT OUTER JOIN)**

   ```sql
   SELECT t1.coluna1, t2.coluna2
   FROM tabela1 t1
   RIGHT JOIN tabela2 t2 ON t1.coluna_comum = t2.coluna_comum;
   ```

   - **Descrição:** Retorna todos os registros da tabela da direita (tabela2), e os registros correspondentes da tabela da esquerda (tabela1). Se não houver correspondência, retorna `NULL` para as colunas da tabela da esquerda.
   - **Exemplo:**  
     ```sql
     SELECT funcionarios.nome, departamentos.nome 
     FROM funcionarios 
     RIGHT JOIN departamentos ON funcionarios.departamento_id = departamentos.id;
     ```

---

## 28. **FULL OUTER JOIN**

   ```sql
   SELECT t1.coluna1, t2.coluna2
   FROM tabela1 t1
   FULL OUTER JOIN tabela2 t2 ON t1.coluna_comum = t2.coluna_comum;
   ```

   - **Descrição:** Retorna todos os registros quando há uma correspondência em qualquer uma das tabelas. Se não houver correspondência, o valor será `NULL` na tabela que não tem correspondência.
   - **Exemplo:**  
     ```sql
     SELECT funcionarios.nome, departamentos.nome 
     FROM funcionarios 
     FULL OUTER JOIN departamentos ON funcionarios.departamento_id = departamentos.id;
     ```

---

## 29. **CROSS JOIN**

   ```sql
   SELECT t1.coluna1, t2.coluna2
   FROM tabela1 t1
   CROSS JOIN tabela2 t2;
   ```

   - **Descrição:** Retorna o produto cartesiano das duas tabelas. Para cada linha da tabela1, todas as linhas da tabela2 são combinadas.
   - **Exemplo:**  
     ```sql
     SELECT funcionarios.nome, departamentos.nome 
     FROM funcionarios 
     CROSS JOIN departamentos;
     ```

## 30. **JOIN com Múltiplas Chaves**

   ```sql
   SELECT t1.coluna1, t2.coluna2
   FROM tabela1 t1
   INNER JOIN tabela2 t2 
   ON t1.chave1 = t2.chave1 AND t1.chave2 = t2.chave2;
   ```

   - **Descrição:** Realiza um `JOIN` com base em múltiplas colunas ou chaves.
   - **Exemplo:**  
     ```sql
     SELECT pedidos.id, clientes.nome 
     FROM pedidos 
     INNER JOIN clientes 
     ON pedidos.cliente_id = clientes.id AND pedidos.empresa_id = clientes.empresa_id;
     ```
