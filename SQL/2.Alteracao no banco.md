Aqui estão alguns códigos SQL que realizam alterações em bancos de dados, além dos exemplos que você já forneceu:

---

## 13. **Adicionar uma Restrição de Chave Primária**

   ```sql
   ALTER TABLE nome_da_tabela
   ADD PRIMARY KEY (nome_da_coluna);
   ```

   - **Descrição:** Adiciona uma chave primária a uma ou mais colunas da tabela.
   - **Exemplo:** `ALTER TABLE funcionarios ADD PRIMARY KEY (id);`

---

## 14. **Remover uma Restrição de Chave Primária**

   ```sql
   ALTER TABLE nome_da_tabela
   DROP PRIMARY KEY;
   ```

   - **Descrição:** Remove a restrição de chave primária da tabela.
   - **Exemplo:** `ALTER TABLE funcionarios DROP PRIMARY KEY;`

---

## 15. **Adicionar uma Restrição de Chave Estrangeira**

   ```sql
   ALTER TABLE nome_da_tabela
   ADD CONSTRAINT nome_da_restricao FOREIGN KEY (coluna_local)
   REFERENCES tabela_referenciada(coluna_referenciada);
   ```

   - **Descrição:** Define uma chave estrangeira que referencia uma coluna de outra tabela.
   - **Exemplo:**  
     ```sql
     ALTER TABLE dependentes
     ADD CONSTRAINT fk_funcionarios FOREIGN KEY (funcionario_id)
     REFERENCES funcionarios(id);
     ```

---

## 16. **Remover uma Restrição de Chave Estrangeira**

   ```sql
   ALTER TABLE nome_da_tabela
   DROP CONSTRAINT nome_da_restricao;
   ```

   - **Descrição:** Remove uma restrição de chave estrangeira da tabela.
   - **Exemplo:** `ALTER TABLE dependentes DROP CONSTRAINT fk_funcionarios;`

---

## 17. **Adicionar uma Restrição Única**

   ```sql
   ALTER TABLE nome_da_tabela
   ADD CONSTRAINT nome_da_restricao UNIQUE (nome_da_coluna);
   ```

   - **Descrição:** Garante que os valores em uma ou mais colunas sejam únicos.
   - **Exemplo:** `ALTER TABLE funcionarios ADD CONSTRAINT unique_email UNIQUE (email);`

---

## 18. **Remover uma Restrição Única**

   ```sql
   ALTER TABLE nome_da_tabela
   DROP INDEX nome_da_restricao;
   ```

   - **Descrição:** Remove uma restrição única de uma coluna.
   - **Exemplo:** `ALTER TABLE funcionarios DROP INDEX unique_email;`

---

## 19. **Criar um Índice**

   ```sql
   CREATE INDEX nome_do_indice
   ON nome_da_tabela (nome_da_coluna);
   ```

   - **Descrição:** Cria um índice para acelerar consultas em uma ou mais colunas de uma tabela.
   - **Exemplo:** `CREATE INDEX idx_nome ON funcionarios(nome);`

---

## 20. **Remover um Índice**

   ```sql
   DROP INDEX nome_do_indice ON nome_da_tabela;
   ```

   - **Descrição:** Remove um índice previamente criado em uma tabela.
   - **Exemplo:** `DROP INDEX idx_nome ON funcionarios;`

Aqui estão exemplos de comandos SQL relacionados a alterações de tipo de coluna, renomear colunas e operações sobre colunas de data:

---

## 21. **Alterar o Tipo de uma Coluna**

   ```sql
   ALTER TABLE nome_da_tabela 
   MODIFY COLUMN nome_da_coluna novo_tipo_de_dado;
   ```

   - **Descrição:** Modifica o tipo de dados de uma coluna existente em uma tabela.
   - **Exemplo:**  
     ```sql
     ALTER TABLE funcionarios 
     MODIFY COLUMN salario DECIMAL(12, 2);
     ```

---

## 22. **Renomear uma Coluna**

   ```sql
   ALTER TABLE nome_da_tabela 
   RENAME COLUMN nome_antigo TO nome_novo;
   ```

   - **Descrição:** Altera o nome de uma coluna em uma tabela.
   - **Exemplo:**  
     ```sql
     ALTER TABLE funcionarios 
     RENAME COLUMN nome TO nome_completo;
     ```

---

## 23. **Alterar Vários Tipos de Colunas ao Mesmo Tempo**

   ```sql
   ALTER TABLE nome_da_tabela 
   MODIFY COLUMN nome_da_coluna1 novo_tipo1,
   MODIFY COLUMN nome_da_coluna2 novo_tipo2;
   ```

   - **Descrição:** Modifica o tipo de dados de múltiplas colunas na mesma operação.
   - **Exemplo:**  
     ```sql
     ALTER TABLE funcionarios 
     MODIFY COLUMN salario DECIMAL(15, 2), 
     MODIFY COLUMN data_contratacao DATE;
     ```

---

## 24. **Adicionar uma Coluna de Data**

   ```sql
   ALTER TABLE nome_da_tabela 
   ADD nome_da_coluna DATE;
   ```

   - **Descrição:** Adiciona uma nova coluna com o tipo de dados `DATE` em uma tabela existente.
   - **Exemplo:**  
     ```sql
     ALTER TABLE funcionarios 
     ADD data_nascimento DATE;
     ```
