## 31. **Concatenar Strings**

   ```sql
   SELECT CONCAT(coluna1, ' ', coluna2) AS nova_coluna
   FROM nome_da_tabela;
   ```

   - **Descrição:** Junta duas ou mais strings em uma única string.
   - **Exemplo:**  
     ```sql
     SELECT CONCAT(nome, ' ', sobrenome) AS nome_completo 
     FROM funcionarios;
     ```


## 40. **Substituir Parte de uma String**

   ```sql
   SELECT REPLACE(coluna, 'antigo_texto', 'novo_texto') AS nova_string
   FROM nome_da_tabela;
   ```

   - **Descrição:** Substitui todas as ocorrências de uma substring por outra substring.
   - **Exemplo:**  
     ```sql
     SELECT REPLACE(nome, 'João', 'Carlos') AS novo_nome 
     FROM funcionarios;
     ```
