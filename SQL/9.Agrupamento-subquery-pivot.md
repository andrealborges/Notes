## Funções de Subqueries

### 67. **Subquery em `WHERE`**

   ```sql
   SELECT coluna1
   FROM nome_da_tabela
   WHERE coluna2 IN (SELECT coluna2 FROM outra_tabela WHERE condição);
   ```

   - **Descrição:** Usa uma subquery na cláusula `WHERE` para filtrar registros com base nos resultados de outra consulta.
   - **Exemplo:**  
     ```sql
     SELECT nome 
     FROM funcionarios 
     WHERE departamento_id IN (SELECT id FROM departamentos WHERE localizacao = 'São Paulo');
     ```

---

### 68. **Subquery em `SELECT`**

   ```sql
   SELECT coluna1, (SELECT coluna2 FROM outra_tabela WHERE condição) AS alias
   FROM nome_da_tabela;
   ```

   - **Descrição:** Usa uma subquery dentro da cláusula `SELECT` para retornar um valor adicional em cada linha.
   - **Exemplo:**  
     ```sql
     SELECT nome, (SELECT AVG(salario) FROM funcionarios WHERE departamento_id = f.departamento_id) AS media_salarial
     FROM funcionarios f;
     ```

---

### 69. **Subquery em `FROM` (Tabela Derivada)**

   ```sql
   SELECT subquery.coluna1
   FROM (SELECT coluna1, coluna2 FROM tabela WHERE condição) AS subquery;
   ```

   - **Descrição:** Usa uma subquery como uma tabela derivada na cláusula `FROM`.
   - **Exemplo:**  
     ```sql
     SELECT subquery.nome, subquery.salario
     FROM (SELECT nome, salario FROM funcionarios WHERE salario > 5000) AS subquery;
     ```

---

### 70. **Subquery com `EXISTS`**

   ```sql
   SELECT coluna1
   FROM nome_da_tabela
   WHERE EXISTS (SELECT 1 FROM outra_tabela WHERE condição);
   ```

   - **Descrição:** Usa uma subquery na cláusula `WHERE` com `EXISTS` para verificar se a subconsulta retorna algum resultado.
   - **Exemplo:**  
     ```sql
     SELECT nome
     FROM funcionarios 
     WHERE EXISTS (SELECT 1 FROM projetos WHERE projetos.gerente_id = funcionarios.id);
     ```

---

### 71. **Subquery com `NOT EXISTS`**

   ```sql
   SELECT coluna1
   FROM nome_da_tabela
   WHERE NOT EXISTS (SELECT 1 FROM outra_tabela WHERE condição);
   ```

   - **Descrição:** Usa uma subquery na cláusula `WHERE` com `NOT EXISTS` para verificar a ausência de resultados.
   - **Exemplo:**  
     ```sql
     SELECT nome
     FROM funcionarios 
     WHERE NOT EXISTS (SELECT 1 FROM projetos WHERE projetos.gerente_id = funcionarios.id);
     ```

---

### 72. **Subquery com `ANY`**

   ```sql
   SELECT coluna1
   FROM nome_da_tabela
   WHERE coluna1 > ANY (SELECT coluna2 FROM outra_tabela WHERE condição);
   ```

   - **Descrição:** Usa uma subquery para comparar valores da coluna com qualquer valor retornado pela subquery.
   - **Exemplo:**  
     ```sql
     SELECT nome 
     FROM funcionarios 
     WHERE salario > ANY (SELECT salario FROM gerentes);
     ```

---

### 73. **Subquery com `ALL`**

   ```sql
   SELECT coluna1
   FROM nome_da_tabela
   WHERE coluna1 > ALL (SELECT coluna2 FROM outra_tabela WHERE condição);
   ```

   - **Descrição:** Usa uma subquery para comparar valores da coluna com todos os valores retornados pela subquery.
   - **Exemplo:**  
     ```sql
     SELECT nome 
     FROM funcionarios 
     WHERE salario > ALL (SELECT salario FROM estagiarios);
     ```

---

### 74. **Subquery com `UNION`**

   ```sql
   SELECT coluna1 FROM tabela1
   UNION
   SELECT coluna1 FROM tabela2;
   ```

   - **Descrição:** Combina o resultado de duas consultas, removendo duplicatas.
   - **Exemplo:**  
     ```sql
     SELECT nome FROM funcionarios
     UNION
     SELECT nome FROM gerentes;
     ```

---

## Funções de Agrupamento

### 75. **Soma dos Valores (SUM)**

   ```sql
   SELECT SUM(coluna_numero) AS soma_total
   FROM nome_da_tabela
   GROUP BY coluna_agrupar;
   ```

   - **Descrição:** Retorna a soma dos valores de uma coluna numérica, agrupada por outra coluna.
   - **Exemplo:**  
     ```sql
     SELECT departamento_id, SUM(salario) AS soma_salarios
     FROM funcionarios
     GROUP BY departamento_id;
     ```

---

### 76. **Média dos Valores (AVG)**

   ```sql
   SELECT AVG(coluna_numero) AS media
   FROM nome_da_tabela
   GROUP BY coluna_agrupar;
   ```

   - **Descrição:** Calcula a média dos valores de uma coluna numérica, agrupada por outra coluna.
   - **Exemplo:**  
     ```sql
     SELECT departamento_id, AVG(salario) AS media_salarial
     FROM funcionarios
     GROUP BY departamento_id;
     ```

---

### 77. **Valor Máximo (MAX)**

   ```sql
   SELECT MAX(coluna_numero) AS valor_maximo
   FROM nome_da_tabela
   GROUP BY coluna_agrupar;
   ```

   - **Descrição:** Retorna o maior valor de uma coluna numérica, agrupada por outra coluna.
   - **Exemplo:**  
     ```sql
     SELECT departamento_id, MAX(salario) AS salario_maximo
     FROM funcionarios
     GROUP BY departamento_id;
     ```

---

### 78. **Valor Mínimo (MIN)**

   ```sql
   SELECT MIN(coluna_numero) AS valor_minimo
   FROM nome_da_tabela
   GROUP BY coluna_agrupar;
   ```

   - **Descrição:** Retorna o menor valor de uma coluna numérica, agrupada por outra coluna.
   - **Exemplo:**  
     ```sql
     SELECT departamento_id, MIN(salario) AS salario_minimo
     FROM funcionarios
     GROUP BY departamento_id;
     ```

---

### 79. **Contar Registros (COUNT)**

   ```sql
   SELECT COUNT(coluna) AS total_registros
   FROM nome_da_tabela
   GROUP BY coluna_agrupar;
   ```

   - **Descrição:** Conta o número de registros em um grupo.
   - **Exemplo:**  
     ```sql
     SELECT departamento_id, COUNT(id) AS numero_funcionarios
     FROM funcionarios
     GROUP BY departamento_id;
     ```

---

### 80. **Agrupar com Condição (HAVING)**

   ```sql
   SELECT coluna_agrupar, SUM(coluna_numero) AS soma_total
   FROM nome_da_tabela
   GROUP BY coluna_agrupar
   HAVING SUM(coluna_numero) > valor;
   ```

   - **Descrição:** Filtra grupos com base em uma condição após o agrupamento.
   - **Exemplo:**  
     ```sql
     SELECT departamento_id, SUM(salario) AS soma_salarios
     FROM funcionarios
     GROUP BY departamento_id
     HAVING SUM(salario) > 100000;
     ```

## Funções de PIVOT

### 81. **PIVOT**
```sql
SELECT *
FROM (
  SELECT nome, departamento, salario
  FROM funcionarios
) AS fonte
PIVOT (
  SUM(salario)
  FOR departamento IN ([Vendas], [TI], [RH])
) AS pivot_tabela;

```

### 82. **UNIONPIVOT**

```sql
SELECT nome, departamento, salario
FROM (
  SELECT nome, [Vendas], [TI], [RH]
  FROM funcionarios_pivot
) AS fonte
UNPIVOT (
  salario FOR departamento IN ([Vendas], [TI], [RH])
) AS unpivot_tabela;
```
