ORDEM DE ESCRITA:
 ``` SQL
SELECT [colunas]
FROM [tabela]
WHERE [condição]
GROUP BY [colunas]
HAVING [condição]
ORDER BY [colunas]
LIMIT [número];
 ```

---

ORDEM DE EXECUÇÃO:

 ``` SQL
FROM [tabela]
WHERE [condição]
GROUP BY [colunas]
HAVING [condição]
SELECT [colunas]
ORDER BY [colunas]
LIMIT [número];
 ```
